# data-product-with-ddd-and-hexagonal-architecture-demo

This project aims to demonstrate how Domain-Driven Design and hexagonal architecture can be leveraged to build data product in Python.

This demo project is meant to be deployed to a Spark environment.

[This article explains the concepts used in this repository](https://blog.octo.com/how-can-domain-driven-design-and-hexagonal-architecture-improve-data-product-development-in-practice).

# Installation guide

```
poetry install
```


 rm -rf data/lakehouse && poetry run python run_orders_ingestion.py to run local
